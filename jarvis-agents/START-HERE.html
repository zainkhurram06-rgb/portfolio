Jarvis agents: start here

Everything that's built, how to open it, and how to test each agent. All commands are PowerShell, run from C:\Users\zaink\portfolio\jarvis-agents unless it says otherwise.

The pipeline boardevery business, in its stage Template libraryevery website template as a file Live template galleryneeds the platform running Owner dashboardowner@luna.example / demo-password

1. Start the platform (two windows, leave them open)

Window 1, the database:

cd platform; npm run db

Window 2, the websites and dashboard:

cd platform; npm run dev

Use a third window for everything below.

2. The flow

EDITH finds leads (1-leads) → MARK researches and builds their site (2-researched, 3-demo-built) → HAPPY checks it (4-checked) → you approve (5-approved) → FRIDAY calls (6-pitched, 7-qualified, 9-lost). Every business is a folder in pipeline\, and its card on the board links to its website, research, check report, calls and history.

3. Test each agent

Every agent has a free sample mode that works now with made-up businesses, and a real mode that needs a key.

EDITH, the lead tracker sample works nowreal needs a Google key

  1. Plan a city and run it (sample data):
    .venv\Scripts\python -m agents.edith plan add 2026-10-27 salon Dubai AE
    .venv\Scripts\python -m agents.edith find --niche salon --city Dubai --country AE
  2. Open the board: new cards in Leads, best score first. Her report (link at the top of the board) shows why every other business was left out.
  3. Change her rules in agents\edith\rules.json (reviews, days since last post, leads per city, spending cap).
  4. Real run: put GOOGLE_PLACES_KEY in jarvis-agents\.env (COWORK-PROMPTS.md, job 2), then switch her to live:
    $env:EDITH_PLACES = "live"; $env:EDITH_SOCIAL = "live"
    She stays inside Google's free allowance, and pauses at the daily social caps, carrying on next run.

MARK, the developer sample works nowreal needs Claude login + an AI key

  1. Add the three sample businesses that have saved research (Glow Lab Nails, Shine Kings, Fadi Plumbing). If they're already on the board, clear the samples first (section 5):
    foreach ($f in Get-ChildItem samples\leads\*.json) { .venv\Scripts\python -m agents.pipeline add $f.FullName }
  2. Research and build them:
    $env:INTERNAL_API_TOKEN = "dev-token-not-secret-0123456789"
    .venv\Scripts\python -m agents.mark research --all
    .venv\Scripts\python -m agents.mark build glow-lab-nails-dubai --brains file:samples\plans\glow-lab-nails.json --label-brains file:x
  3. On the board, open the website: their logo, colours, photos and reel, filled into a template. Book buttons go to the live booking page.
  4. Real research uses your own Chrome: run claude then /login once, keep Chrome open with the Claude in Chrome extension, then:
    $env:MARK_RESEARCH = "chrome"; .venv\Scripts\python -m agents.mark work
    The words need an AI: set ANTHROPIC_API_KEY or DEEPSEEK_API_KEY, or have Codex logged in.

HAPPY, quality check works now

  1. Check every website in Demo built:
    .venv\Scripts\python -m agents.happy check --all
  2. Passed sites move to Checked. Each card links to HAPPY passed / failed, his report with every rule.
  3. Your rules: agents\happy\rules.json. Turn each one on or off, and set it to block (fails the site) or warn (noted only).
  4. Then you approve the ones you like:
    .venv\Scripts\python -m agents.pipeline move glow-lab-nails-dubai approved

FRIDAY, the sales caller sample works nowreal needs ElevenLabs + Twilio

  1. Sample calls (no phone line, made-up results):
    .venv\Scripts\python -m agents.friday call --all --any-time
    Interested goes to Qualified, call back to Pitched, no to Lost. Each card links to calls: the summary and transcript.
  2. Would she call someone right now, and if not, why:
    .venv\Scripts\python -m agents.friday check glow-lab-nails-dubai
  3. Edit what she says in agents\friday\pitch.md. Set company_name and price_text in agents\friday\rules.json.
  4. Real test calls ring your phone, never the business:
    $env:ELEVENLABS_API_KEY = "..."; $env:FRIDAY_PHONE_NUMBER_ID = "..."; $env:FRIDAY_TEST_NUMBER = "+971..."; $env:FRIDAY_VOICE = "live"
    .venv\Scripts\python -m agents.friday setup
    .venv\Scripts\python -m agents.friday call glow-lab-nails-dubai
    .venv\Scripts\python -m agents.friday collect --all
  5. Calling real businesses needs FRIDAY_LIVE=yes and the country switched on in rules.json. Check the rules for AI calls to businesses in that country first. Every country starts off.
