# jarvis-agents (work in progress)

Zain's agent team. Paused while we agree the plan.

- `agents/developer/` turns a business's details into a branded demo website.
  - `templates/` one folder per design: `clinic`, `homeservices`, `salon` so far.
  - `brand.py` the site config every template reads.
  - `build.py` pours a config into a template (no AI, free, instant).

Lives in the portfolio repo on a working branch only until it gets its own repo.
