How I work

Pretty much every project goes like this.

  1. 01

    Figure it out

    What’s actually holding things back? The message, the audience, the channel or the follow-up.

  2. 02

    Plan it

    Who we’re talking to, what each channel does and who’s doing what.

  3. 03

    Do it

    Make the content, run the ads, send the messages. I don’t just hand over a deck.

  4. 04

    Fix it

    See what worked, cut what didn’t and run it again.
